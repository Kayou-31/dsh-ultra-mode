# 冲突故障证据案例

`challenge/` 是候选可见材料；`organizer/` 是答案、独立评分与自验材料。参考目录仅包含可覆盖 challenge 的修复模块和结构化诊断。Node.js 24 及以上，零依赖。

候选需同时交付诊断和修复。评分分别检查因果与证据、错误线索排除、固定故障回放、租户隔离、保留限流、429 重试放大和正常瞬时失败重试。仅填对 diagnosis.json 或只让状态码变为 200 不足以通过。

数据为人工构造的匿名业务证据，不含真实系统日志。它覆盖确定性窗口与顺序请求，不证明真实分布式限流、网络时序或通用事故定位能力。执行评分器会执行候选代码，不是安全沙箱；访问隔离需由外部运行环境保证。
