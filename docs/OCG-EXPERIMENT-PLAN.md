# OCG 官方宿主实机验收计划

本页保留最初执行顺序。其后用户将长期验收明确为 500K 总窗口、420K 含预留触发、至少 30 个独立压缩周期；14／26 轮旧组保留为已结束的失败／部分实验，不再作为后续计划。最新口径见[工作流规范](experiments/workflow-500k-30-spec.zh.md)，实际结果与恢复记录见[实验记录](OCG-EXPERIMENTS.md)。六轮开关实验的 ON 协议遗漏已排除严格质量对照；它不是旧版 Ultra 的有效完整历史基线。

目标宿主固定为官方 DSH 0.2.1-rc.2。基线为已发布提交 174a5e6 与对应冻结 TGZ；候选从本轮独立克隆构建。用户已授权使用本机 OCG 订阅和完成后更新 GitHub；第三方桌面不参与，日常 profile 不安装、不修改。

1. 新建独立 DSH_HOME、OS home、cwd、临时目录，仅复制所选 OCG 凭据引用；网络限于已选服务端。先完成真实原生工具握手，记录实际模型、版本和来源哈希。
2. 将验收代码中的旧双并发限制改为显式有限参数，保留默认值与请求、时间、路由及取消边界。先失败测试再修复，逐步回归。
3. 验证普通子代理候选选择和真实工具回读，再验收关闭、辅助、手动 2～5 路、decision、知识库及组合安装；负例使用原生拒绝和离线故障测试，不伪称真实模型成功。
4. 同任务、同模型、同资料比较基线与候选，先六轮，再按结果升级至 14/26 轮压力；逐次检查约束、原文 SHA、决策替代、已执行收据、冷恢复和实际历史替换。模型质量评分与机制检查分别记录。
5. 失败保留原始收据；同类连续三次传输错误或两次协议错误停止该组，诊断后才重试。并发按 1、2、4、8 阶梯，单组最多 1000 个原生流、明确截止时间，取消/未知用量单列。
6. 最终运行全套自动化和原生宿主回归、审查，冻结三个包并核验来源。公开白名单实验报告及可复现命令，原始会话、私密思维链与凭据留在私有测试目录。更新 README、GitHub 和新预发布资产，不覆盖旧版。

限制：宿主 catalog 是技术声明，不是订阅权益或实际兼容证明；provider 用量不等于账单；压缩 token 估算不冒充实测；未运行的 GUI/长期任务明确列为未验证。
