# 0.4.0-rc.3 界面修复验证

记录日期：2026-10-12。目标宿主为 **DSH Desktop / Host 0.2.0-rc.2**。最终文字客户端已经完成本机安装与真实界面检查；本文先记录发布前结果，GitHub 同步及最终资产核对随后补充。

## 问题与改动

rc.2 较长的协作与 Ultra 双按钮挤占共享工具栏，导致宿主收起原生模型名称。宿主的 `observeControlRow` 比较左右控件组宽度、间隔与可用空间，超过预算时设置 `data-model-compact`。只检查插件自身没有溢出不能证明宿主模型文字保留。

图标中间版恢复了模型名称，但用户要求保留文字。最终方案显示「协作」／英文「Team」以及「Ultra 关／辅助／2–5」，字体为 13 像素。协作与 Ultra 仍为独立开关，完整说明保留在 title、可访问描述和菜单中；忙碌、保存和错误状态不会撑宽横排按钮。

| 布局 | 插件触发区尺寸 |
| --- | --- |
| 常规 | 协作 44 + 间隔 4 + Ultra 84 = **132 CSS 像素** |
| 宿主容器不超过 440 像素 | 协作 44 + 间隔 4 + Ultra 48 = **96 CSS 像素**；仍保留模式文字 |

所有 CSS 均限定在插件类名中，没有修改宿主 DOM 或模型选择器样式。菜单保留原有上下方向选择，并增加视口两侧 16 像素边界约束。
