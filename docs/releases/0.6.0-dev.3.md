# v0.6.0-dev.3：完整 Ultra 与两个独立附属插件

同一 Release 提供完整 Ultra `0.6.0-dev.3`、Memory `0.1.0-dev.1`、Decision `0.1.0-dev.1`。这是预发布，沿用已验收开发版本号，不声称稳定版。TGZ从GitHub分发，未发布到npm，不改日常DSH环境。

## 安装选择与源码

- 完整 Ultra：仓库根目录；保留关闭、辅助、手动2～5路、Team、模型池、治理、证据、上下文和知识。
- Memory：`packages/dsh-ultra-memory/`；原始证据检索、可选压缩、同profile显式授权跨项目知识，不创建模型。
- Decision：`packages/dsh-ultra-decision/`；普通子代理协作、工具调用、多模型池、只读旁路及意图/诊断/验收能力。
- 支持任意单包、Memory＋Decision、Ultra＋Memory；同scope仅启用一个Ultra或Decision协调入口。Memory＞Ultra＞Decision选择单份证据配置，不合并授权。详见[组合与回滚](../companion-plugins.md)。

压缩和全局知识默认关闭，额外Decision旁路默认关闭，保留用户的手动模式选择。共享索引不扩大权限，历史/知识仅是资料，不构成新授权。

## 验证与限制

- 原生目标DSH **0.2.1-rc.2**；旧0.2.0-rc.2另做SDK回归，不据此宣称全局知识可用，缺原生profileContext失败关闭。
- 同一498项套件：新SDK496通过/2跳过；旧SDK495通过/3跳过；均0失败。两项Windows链接权限跳过，旧SDK额外跳过精确新SDK的Team夹具。
- 三个精确TGZ：9组24个原生CLI进程，741条断言、218条离线脚本stream，峰值2，网络0。覆盖跨项目授权/来源核验、跨profile拒绝、冷恢复、组合顺序与单方卸载、多候选实际请求、子代理工具、配置持久化、只读辅助、取消及完整Ultra治理。
- 两轮原生surface token估算50902→2082、53579→4250，原文引文和完整SHA可读回。测试为合成关闭历史，轮间显式原生resume；不是连续真实模型长任务，也不是计费token或质量优势证明。
- 真实模型、多provider在线兼容、长期语义漂移、完整Electron UI、独立Decision对意图/诊断/最终验收的专门原生完整闭环未验证。独立Decision已启用治理并跑只读assist，不能因此补算完整闭环。
- 日常profile四项有限指纹检查：3同、1项cordis.patch.yml变化，来源未知；未回写/恢复，不能声称日常配置全部未变。运行器及24条启动记录指向隔离profile，不据此归因该变化。
- diff --check保留两份派生core-src继承原orchestrator.ts末尾空行的诊断；四者SHA一致，其他诊断失败，补丁正反逐字节验证通过。
